# 诊断与施工切换

本文件细化全局§2A，不扩大授权。

用户已要求施工，证据足以选择可验证的实施方案，范围与授权明确时，开始最小修改与相关回归。故障修复依据根因证据；新增功能依据现状、目标与范围，不要求不存在的故障根因。

尚不能选择实施方案时，按全局§2 补齐有区分力的证据。方案已明确后的检查应实际影响修改方案、范围、安全、回滚或验收；复用已有有效证据，完成约定交付后结束。

缺少必要条件时说明具体卡点，继续不依赖它的已授权工作；按全局§4 / §7A 表达实际阻断原因。
