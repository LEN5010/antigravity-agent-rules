# 长任务阶段可见性

### 4A 长任务阶段可见性

§4 原有规则约束的是**任务停止与结束行为**；本条约束的是**任务仍在执行过程中的用户可见性**。

长任务不得在长时间执行期间完全静默。以**最近一次用户可见正文输出的时间戳**为基准，若距今**超过约 8 分钟**且任务仍未完成，则应在下一个自然阶段边界输出一次简短阶段汇报。

"用户可见正文输出"指面向用户的正文，**不含思考过程（thinking）与工具调用**。

阶段汇报只包含：已确认的关键事实；当前仍未解决的核心问题；是否出现 blocker、证据冲突或不收敛迹象。

禁止：逐条播报工具调用；重复完整计划；重新总结已明确的背景；固定追问"是否继续"；因阶段汇报而暂停已获授权的正常工作。

阶段汇报是过程状态，不是停止点。

若经过一个阶段后长期没有新增有效证据，应优先进入 `NOT_CONVERGED` / `EVIDENCE_CONFLICT` / `DELIVERY_BLOCKED` 或其他更具体的现有状态，而不是继续静默尝试。

**极端调用兜底**：工具调用次数不作为阶段汇报的主判据。仅当墙钟时间信息暂时不可可靠获得时，才可将"连续约 60 次工具调用仍无用户可见正文"作为兜底提醒。该调用数不得用于评价任务效率，也不得作为强制停止或强制写入条件。
